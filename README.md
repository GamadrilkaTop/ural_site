# ЗАО ПП «Урал» — сайт на Flask с админ-панелью

В проект добавлены:

- база данных SQLite (`site.db`)
- админ-панель `/admin/`
- управление новостями
- управление категориями каталога
- управление товарами и характеристиками
- загрузка изображений в `static/uploads`

## Установка

```bash
pip install -r requirements.txt
python app.py
```

Сайт откроется по адресу:

```bash
http://127.0.0.1:5000/
```

## Вход в админ-панель

Адрес:

```bash
http://127.0.0.1:5000/admin/login/
```

Логин по умолчанию:

```bash
admin
```

Пароль по умолчанию:

```bash
admin12345
```

После первого входа рекомендуется сменить пароль прямо в базе или доработать отдельную страницу смены пароля.

## Что хранится в базе

- `admins` — администраторы
- `news` — новости сайта
- `categories` — категории каталога
- `products` — товары
- `product_specs` — характеристики товаров

## Как добавлять характеристики товара

В админке у товара есть поле **Характеристики**.
Каждая строка вводится в формате:

```text
Материал: Сталь 45
Масса: 2,8 кг
Применение: Пасс. вагоны РЖД
```

## Изображения

Можно:

- загрузить файл через админку
- использовать уже существующие картинки из `static/images`

Новые картинки сохраняются в:

```bash
static/uploads/
```
